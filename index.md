A small macOS app for renaming a batch of video files while watching them —
built for the "pile of IMG_XXXX.mov camera files" problem. Keyboard-first:
**⏎** renames the current file on disk and advances, **↑ / ↓** navigate
without saving, **⌘⌫** moves the current file to the Trash.

Requires macOS 26.

[Download the latest release →](https://github.com/deskrabbits/renamatic/releases/latest)

## How it works

1. **Batch Builder** — drag video files into the window (or the `+` button /
   Finder "Open With") to build a batch, then start renaming.
2. **Rename** — step through the batch with a looping video preview and a
   rename field. Once every file is renamed, the batch clears.

Renamatic is free and [open source](https://github.com/deskrabbits/renamatic)
under the MIT license.
