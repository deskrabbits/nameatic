Rename a whole folder of videos without touching the mouse.

Nameatic plays each clip, you type what it is, press Return, and the next one starts. That’s the whole app.

Download for Mac Version 1.0 · macOS
01

Drop in a batch

Drag a folder of downloads, exports or camera dumps onto the window. Every clip lines up in a queue.

02

Watch and type

The clip plays as soon as it’s selected, and the name is already highlighted. Just start typing.

03

Return. Repeat.

Return saves and moves on. The file keeps its extension. Twenty videos take about as long as twenty sentences.

Built for big batches

When you’ve got hundreds of clips all named v12044gd0000d8ov9.mp4 you’ll be thankful for Nameatic. It’s made to do one thing, and one thing only: get out of the way so you can rename videos.

Keyboard-first, all the way down

No double-clicks, no waiting for Finder to make the name editable, no Quick Look juggling. Focus never leaves the name field.

Made for AirPods

Trying to use Finder’s Quick Look with a bunch of short videos is an exercise in laggy frustration. Nameatic fixes that. It’s so smooth you’ll think you’re using wired headphones (which you can also use).
